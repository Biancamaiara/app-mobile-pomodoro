# ⏱️ Pomodoro App

Aplicativo Android desenvolvido em **Kotlin** utilizando o **Android Studio**, com integração ao **Firebase**.  
Este projeto foi desenvolvido como parte de uma matéria da faculdade e tem como objetivo auxiliar no controle do tempo de estudo usando a técnica **Pomodoro**.

---

## 🎯 Funcionalidades

- Controle de tempo de estudo baseado na técnica Pomodoro  
- Interface simples e intuitiva  
- Aba para **anotações rápidas** durante ou após os ciclos de estudo  
- Armazenamento de dados no **Firebase**

---

## 🛠️ Tecnologias Utilizadas

- **Kotlin**
- **Android Studio**
- **Firebase**
- **Gradle**
